# Data

This folder contains the four Fitbit CSV files used in the Bellabeat case study.

- BellaBeat Case Study - dailyActivity_merged.csv
- BellaBeat Case Study - dailyCalories_merged.csv
- BellaBeat Case Study - dailyIntensities_merged.csv
- BellaBeat Case Study - weightLogInfo_merged.csv

Source: [Fitbit Fitness Tracker Data on Kaggle](https://www.kaggle.com/datasets/arashnic/fitbit)

The files are included to make the cleaning and analysis workflow reproducible.
